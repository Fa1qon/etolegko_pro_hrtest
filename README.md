# netspeed

Консольный замер скорости скачивания: 10 последовательных запросов к адресу, каждый ответ читается до конца, в консоль выводится скорость.

## Запуск

Python 3.8+, только стандартная библиотека.

```bash
python netspeed.py https://speedtest.selectel.ru/10MB
```
```
39.73 Mbit/s
```

## Единицы

**Mbit/s**: мегабиты в секунду, 1 Mbit = 10⁶ бит.

## Как считается

1. Адрес проверяется до первого запроса: схема `http://` или `https://`, указан хост, порт от 0 до 65535, нет пробелов и управляющих символов. Иначе выводится ошибка и код выхода `2`.
2. 10 запросов выполняются последовательно. Ответ читается до последнего байта блоками по 64 KB и не сохраняется.
3. Неудачный запрос (HTTP 4xx/5xx, нет данных 10 с, обрыв соединения, ответ короче заявленного `Content-Length`) выводится в stderr и в расчёт не входит.
4. После 3 неудач подряд замер останавливается. Если до этого были удачные запросы, скорость считается по ним.
5. По удачным запросам:
   - общий объём = сумма байт;
   - среднее время запроса = от отправки запроса до последнего байта ответа;
   - скорость = общий объём × 8 / (среднее время × число удачных запросов) / 10⁶.

В stdout выводится только скорость. Коды выхода: `0` есть результат, `1` все запросы неудачны, `2` неверный адрес.

## Тесты

```bash
python -m unittest -v
```

Тесты используют локальный HTTP-сервер. Проверяются: ровно 10 запросов и одна строка в stdout, пропуск неудачных запросов, обрезанный ответ, остановка после 3 неудач подряд, отказ от невалидных адресов, формула скорости.
